## Critical Corrections Made

### 1. Accounts Receivable Payment Fields

**v1.0 (INCORRECT):**
```json
{
  "amount": 50000.0,
  "paymentDate": "2026-01-10",
  "description": "Partial payment",
  "referenceNumber": "CHK-001"
}
```

**v3.0 (CORRECT):**
```json
{
  "accountsReceivableId": {arId},
  "receiptDate": "2026-01-10",
  "amountReceived": 50000.0,
  "paymentMethodId": 1,
  "reference": "CHK-001",
  "currencyId": null,
  "exchangeRate": 1.0
}
```

**Actual DTO:** `CreateReceiptDto`
- Removed: `amount`, `paymentDate`, `description`, `referenceNumber`
- Added: `amountReceived`, `paymentMethodId`, `currencyId`, `exchangeRate`
- Renamed: `reference` (from `referenceNumber`)
- Note: `accountsReceivableId` auto-populated by controller from route parameter

---

### 2. Purchase Order Line Items

**v1.0/v2.0 (INCORRECT):**
```json
{
  "itemId": {itemId},
  "description": "Surgical Gloves",
  "quantity": 10,
  "unitPrice": 5000.0,
  "amount": 50000.0,
  "chartOfAccountId": 51
}
```

**v3.0 (CORRECT):**
```json
{
  "itemId": {itemId},
  "description": "Surgical Gloves",
  "quantity": 10,
  "unitPrice": 5000.0,
  "lineTotal": 50000.0
}
```

**Actual DTO:** `POLineDto`
- Removed: `chartOfAccountId`, `amount`
- Renamed: `amount` → `lineTotal`
- Note: GL account references belong in inventory item setup, not PO lines

---

### 3. Vendor Bill Creation Fields

**v1.0 (INCORRECT):**
```json
{
  "poId": {poId},
  "vendorId": {vendorId},
  "invoiceDate": "2026-01-10",
  "dueDate": "2026-02-10",
  "invoiceAmount": 90000.0,
  "invoiceNumber": "VB-0001",
  "description": "Vendor bill for PO-0001",
  "branchId": null,
  "status": 1
}
```

**v3.0 (CORRECT):**
```json
{
  "purchaseOrderId": {poId},
  "vendorId": {vendorId},
  "billDate": "2026-01-10",
  "dueDate": "2026-02-10",
  "totalAmount": 90000.0,
  "branchId": null
}
```

**Actual DTO:** `CreateVendorBillDto`
- Removed: `invoiceNumber`, `description`, `status`
- Renamed: `poId` → `purchaseOrderId`, `invoiceDate` → `billDate`, `invoiceAmount` → `totalAmount`
- Note: Invoice number is auto-generated by system, status set to Draft (1) by default

## New APIs Added in v3

### Look Module - Currency Types
**Location:** `/api/Look/CurrencyType`  
**Controller:** `CurrencyTypeController`  
**Status:** ✅ Implemented

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/GetCurrencyTypeDDL` | GET | Get dropdown list with exchange rates |
| `/GetList` | POST | Get filtered list with pagination |
| `/GetDetail/{id}` | GET | Get single record details |
| Create | POST | Create new currency type |
| Update | PUT | Update currency type |

### Look Module - Branches
**Location:** `/api/Look/Branch`  
**Controller:** `BranchController`  
**Status:** ✅ Implemented

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/GetBranchDDL` | GET | Get dropdown list (allowed branches) |
| `/GetChildBranchDDL` | GET | Get sub-branch list |
| `/GetList` | POST | Get filtered list with pagination |
| `/GetDetail/{id}` | GET | Get single branch details |
| Create | POST | Create new branch |
| Update | PUT | Update branch |
| Delete | DELETE | Delete branch |

### Look Module - Exchange Rates
**Location:** `/api/Look/CurrencyExchangeRate`  
**Controller:** `CurrencyExchangeRateController`  
**Status:** ✅ Implemented

| Endpoint | Method | Purpose |
|----------|--------|---------|
| Create | POST | Create exchange rate |

| GetAll | GET | Get rates for specific date |
